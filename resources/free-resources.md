# 🆓 Free Resources

Always check each provider's current terms. Links change over time. If one breaks, open an issue or fix it with a pull request.

## ☁️ Cloud computing (19 Oct)
- [Cloud Track](https://github.com/GDG-TUM/Cloud-Track-GDG-on-Campus-TUM) and its [site](https://gdg-tum.github.io/Cloud-Track-GDG-on-Campus-TUM/)
- [Google Cloud Skills Boost](https://www.skills.google/): free labs and learning paths
- [Google Cloud documentation](https://docs.cloud.google.com/docs)

## 🔐 Cybersecurity (26 Oct)
- [Cybersecurity Track](https://github.com/GDG-TUM/cybersecurity-track): includes an account and phone safety checklist
- [Have I Been Pwned](https://haveibeenpwned.com): check whether your email appears in known breaches
- [TryHackMe](https://tryhackme.com): guided beginner labs

## 🤖 AI and ML (2 Nov)
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)
- [Kaggle Learn](https://www.kaggle.com/learn): short, hands-on courses

## 📊 Data science (9 Nov)
- [Kaggle Learn](https://www.kaggle.com/learn): Python, pandas and data visualisation courses
- Use **public, open datasets** with no personal information

## 🌐 Web, 📱 mobile and 🎨 design (16 Nov)
- [MDN Web Docs](https://developer.mozilla.org): the reference for HTML, CSS and JavaScript
- [Android Developers](https://developer.android.com): official docs and courses
- [Material Design](https://m3.material.io): design guidance for apps

## 🛠️ Git and GitHub
- [GitHub Skills](https://github.com/SKILLS): interactive courses

## 💜 Communities for women in tech
- [Women Techmakers](https://developers.google.com/womentechmakers): Google's community and programmes for women in tech
- [AkiraChix](https://akirachix.com): Kenyan organisation supporting women in tech
