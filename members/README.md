# 👋 Introduce Yourself

Adding yourself here is a gentle **first step into GitHub**. It teaches the fork, branch, commit and pull request flow on something safe. You do not need to use GitHub to attend events.

## Steps
1. **Fork** this repository (button at the top right on GitHub)
2. **Clone** your fork:
   ```bash
   git clone https://github.com/<your-username>/women-in-tech.git
   cd women-in-tech
   ```
3. **Create a branch:**
   ```bash
   git checkout -b add-profile-<your-username>
   ```
4. **Copy the template** to a new file named after your GitHub username:
   ```bash
   cp members/_template.md members/<your-username>.md
   ```
5. **Fill it in** (share only what you are comfortable making public)
6. **Commit and push:**
   ```bash
   git add members/<your-username>.md
   git commit -m "docs: add profile for <your-username>"
   git push origin add-profile-<your-username>
   ```
7. **Open a pull request** on GitHub. A maintainer reviews and merges it. Welcome! 🎉

## Rules
- One file per person, named `<github-username>.md`
- Do not share phone numbers, addresses or anything private
- Keep it friendly and professional
